shadcn copies the components into your project rather than installing them as a dependency, so their classes are in your copy and nowhere else. They are written with your theme's tokens — `text-primary`, `text-muted-foreground`, `text-destructive` — so they match the rest of your UI without anything being set.

## Edit your copy

In `components/command-line.tsx`, each kind of word takes its classes from the `tone` map at the top of the file:

```tsx
const tone = {
  program: 'font-medium text-foreground',
  subcommand: 'text-foreground',
  flag: 'text-primary',
  value: 'text-sky-700 dark:text-sky-300',
  operator: 'text-muted-foreground',
  redirect: 'text-muted-foreground',
  word: 'text-foreground/80',
  unread: 'text-destructive underline decoration-wavy',
}
```

<OpenInV0 item="command-line" />

A flag that widened the answer adds `rounded-sm bg-primary/15`, and the program another one hands over to adds a dotted underline; both are in `commandLinePartClassName`, just below the map.

In `components/sentence.tsx`, each value is drawn by the `Value` element — shadcn's `Badge`, set to sit inline and wrap with the sentence, around a `<code>`:

```tsx
<Badge
  asChild
  variant="outline"
  className="inline rounded-sm border-transparent bg-primary/10 px-1 py-0.5 font-mono text-[0.85em] font-normal whitespace-normal text-primary"
>
```

<OpenInV0 item="sentence" />

Change these and every use of the component follows.

## Override one use

For one place that needs something else, pass `renderValue` to [`Sentence`](/docs/react/sentence) or `renderPart` to [`CommandLine`](/docs/react/command-line), and draw with whatever classes you like. Here each value takes a colour and an icon by its `role`, so a URL, a host, a file and a user each look like what they are:

<ComponentPreview name="sentence-by-role-demo">

```tsx
import type { Role } from 'cmd-facts'
import { Cpu, FileText, Globe, Server, User } from 'lucide-react'
import type { LucideIcon } from 'lucide-react'
import { CommandLine } from '@/components/command-line'
import { Sentence } from '@/components/sentence'
import { Badge } from '@/components/ui/badge'

const command = 'curl -o dump.sql https://db.example.com/export && chown alice dump.sql && ssh admin@db.internal'

// One look per kind of value, so a reader tells a host from a file at a glance. A role not listed keeps the default.
const byRole: Partial<Record<Role, { icon: LucideIcon; className: string }>> = {
  url: { icon: Globe, className: 'bg-sky-400/15 text-sky-700 dark:text-sky-300' },
  host: { icon: Server, className: 'bg-violet-400/15 text-violet-700 dark:text-violet-300' },
  path: { icon: FileText, className: 'bg-amber-400/15 text-amber-700 dark:text-amber-300' },
  user: { icon: User, className: 'bg-emerald-400/15 text-emerald-700 dark:text-emerald-300' },
  pid: { icon: Cpu, className: 'bg-rose-400/15 text-rose-700 dark:text-rose-300' },
}

export default function Page() {
  return (
    <main className="mx-auto flex max-w-2xl flex-col gap-4 p-8">
      <CommandLine command={command} className="rounded-md border px-3 py-2 text-sm" />
      <p className="text-xl leading-relaxed">
        <Sentence
          command={command}
          renderValue={(v) => {
            const look = byRole[v.role]
            return (
              <Badge
                variant="secondary"
                title={`${v.role}: ${v.written.join(', ')}`}
                className={`font-mono text-[0.85em] font-normal ${look?.className ?? ''}`}
              >
                {look && <look.icon aria-hidden />}
                {v.text}
              </Badge>
            )
          }}
        />
      </p>
    </main>
  )
}
```

</ComponentPreview>

`className` on either component goes to its outer element, merged with `cn`.

## Plain CSS

The default pieces carry what they are as attributes — `data-kind` and `data-role` on the line, `data-role` on a sentence's values — so a stylesheet can reach them without touching the components:

```css
[data-slot='command-line'] [data-kind='flag'] { color: hotpink; }
[data-slot='sentence'] [data-role='url'] { color: skyblue; }
```
